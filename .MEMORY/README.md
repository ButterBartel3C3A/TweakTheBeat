# .MEMORY — 项目协作记忆

本文件夹是 TweakTheBeat 项目的**跨 agent 协作记忆**：任何参与本项目的 Claude/AI 会话都从这里恢复项目上下文，不依赖任何单个会话的历史。随仓库一起提交、推送、评审。

## 使用约定（agent 必读）

1. 进入项目先读 `INDEX.md`，再按需读具体文件。
2. 工作过程中产生下列信息时，须写入对应文件并提交（这是协作义务，不是可选项）：
   - 需求澄清/变更/用户新指示 → `iteration.md`（时间倒序追加，保留历史）
   - 技术决策或待决事项 → `decisions.md`（ADR 风格）
   - 环境事实变化（路径/设备/依赖/约束） → `environment.md`（直接修正为最新事实）
   - 项目状态（阶段/下一步/阻塞） → `state.md`（直接改写当前态）
   - 稳定定位的变化 → `project.md`
3. 每次更新后 bump 文件 frontmatter 的 `updated` 字段，并同步 `INDEX.md` 的 hook 描述（如有变化）。

## 保密约定（硬性）

1. **外部数据源**（用例文档与固件参考源码所在库，商用闭源）：其名称/路径/内部结构禁止出现在任何推送云端的文本（仓库文件、commit message 均在内），也不得将其内容推送云端；本地路径只存本机会话个人记忆（不推送）。
2. **设备/品牌脱敏**：仓库文本一律以代号「**目标设备**」指代被测设备；不出现产品名/品牌名/设备广播名/具体协议 UUID/帧字节值。这些细节以本机工作树内的需求文档（未跟踪，勿提交）与会话个人记忆为准。
3. 需要具体设备细节的 agent：读本机工作树的 `ble-automation-prompt.md`（禁止提交/推送）或查会话个人记忆；仓库的外部读者看不到这些信息。
4. commit message 同样遵守以上全部条款。

## 文件格式规范

- 除 `INDEX.md` 外，每个文件带 YAML frontmatter：`title`（文件用途）、`type`（分类：meta/project/iteration/environment/decisions/state）、`updated`（最后更新日期，绝对日期）。
- 正文 markdown；语言：中文（代码/路径/标识符除外）。
- 日志类文件（iteration/decisions）只追加不改写历史条目；事实类文件（environment/state/project）直接更新为最新事实。
- 只存结论、指针、事实摘要，不复制大型文档内容（如 205 用例表等大文档不复制进 .MEMORY；其访问方式遵循上方保密约定）。

## 与个人记忆的分工

- 仓库内 `.MEMORY/` = 项目唯一事实来源（跨 agent 共享、随仓库推送）。
- 会话个人记忆（`~/.claude/...`）只保留指向本文件夹的指针与用户个人偏好，不重复项目内容。
